Retire = soft delete: the entry stops generating new POs, but old codes still decode. Nothing is ever hard-deleted.

Code: CO-BU-PRJ-S-VV-NNNNN (21 chars; QuickBooks Online PO number limit is 21). VV = 2-character vendor code. S: one-character spend category (C consumable/recurring, O one-time, R replacement, D R&D, plus any added; new categories must use a single unused letter/digit so the code length never changes). NNNNN is a global sequence (up to 99,999), never reused. Tool/item lives in the log record, not the code. Future: supervisor-only generation and OneDrive-based permissions; each record carries an issuedBy field for that.
